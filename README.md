# 영상 피드백 편집기 (Video Feedback Editor)

Claude로 영상을 편집할 때, 고칠 점을 말로 설명하는 대신 **영상 위에 직접 표시**해서 전달하는 웹 도구입니다.

👉 **바로 쓰기: https://jesuswithme.github.io/video-feedback-editor/**

## 할 수 있는 것
- **위치 주석** — 고칠 장면에서 멈추고 화면을 클릭(핀)하거나 드래그(영역)한 뒤 코멘트. 시간·위치(「오른쪽 위」)·좌표가 자동 기록
- **구간 주석** — 타임라인에서 구간을 고른 채로 주석을 달면 "0:08–0:10 구간" 주석
- **직접 편집** — 구간 잘라내기, 자막 넣기(드래그로 이동·길이 조절), 원본 소리 크기, 자막 크기·위치
- **클로드에게 보내기** — 사람용 수정 요청 글 + 기계용 JSON을 한 번에 복사
- **주석 시트 이미지** — 주석 단 장면을 번호와 표시가 들어간 이미지 한 장으로
- **불러오기** — Claude가 돌려준 JSON을 붙여넣어 편집기에 다시 반영
- 되돌리기, 단축키, 같은 영상을 다시 열면 이전 작업 이어 하기(브라우저 저장)

## 쓰는 법
1. 위 주소를 열고 영상을 끌어다 놓기
2. 고칠 곳마다 멈춤 → 화면 클릭/드래그 → 코멘트 → Enter
3. 「클로드에게 보내기」 → 전체 복사 → Claude 채팅에 붙여넣기 (주석 시트 이미지도 함께 올리면 더 정확)

## 단축키
| 키 | 동작 |
|---|---|
| Space | 재생 / 멈춤 |
| ← → | 1초 이동 (Shift: 0.1초) |
| , . | 한 프레임 이동 |
| I / O | 선택 구간 시작 / 끝 |
| X | 선택 구간 잘라내기 |
| S | 자막 넣기 |
| C | 주석 칸으로 |
| Ctrl+Z | 되돌리기 |

## 개인정보
영상은 브라우저 안에서만 열립니다. 서버로 업로드되지 않습니다. 파일 하나(`index.html`)로 된 정적 앱이라 내려받아 오프라인으로도 쓸 수 있습니다.
